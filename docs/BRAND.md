# Marque VIRELIA

**VIRELIA** est le nom de la plateforme. Il figure dans le logo, les titres, les pages publiques, les emails, les réglages admin et la documentation.

**LIA** est le compagnon générique par défaut. L’utilisateur peut choisir Simon, Junior, Kevin, Ludmilla, Annabella ou LIA, puis sélectionner un archétype et un trait de caractère.

Le ton est intime mais soigné. Il ne doit être ni infantilisant, ni provocant gratuitement, ni présenté comme un remplacement de l’humain. Le produit privilégie les phrases concrètes, les limites lisibles et une interface calme.

## Règles produit

| Élément | Règle |
|---|---|
| Plan Gratuit | 150 messages dans une fenêtre glissante de 24 heures, deux compagnons actifs maximum. |
| Plan Premium | Messages illimités sous réserve d’anti-abus, compagnons supplémentaires et fonctions avancées. |
| Traits matures | Invisibles tant que l’utilisateur n’a pas explicitement confirmé avoir 18 ans ou plus. |
| Hors périmètre v1 | Audio, vidéo, saisie vocale, uploads, drag-and-drop et génération d’images par le compagnon. |
| Sécurité | Aucun secret provider dans le navigateur ; les sections non configurées restent explicitement inactives. |
